VEMU AI — FULL PROJECT (STAGES 1–5)

1. Install Python 3.11 64-bit from https://www.python.org/downloads/windows/ (enable Add Python to PATH).
2. Open this folder in File Explorer. Click the address bar, type cmd, press Enter.
3. Run:
   py -m venv .venv
   .venv\Scripts\activate
   python -m pip install --upgrade pip
   python -m pip install -r requirements.txt
4. Copy .env.example to .env (optional settings; can start with blanks).
5. Run: python vemu.py
6. Say: Hey VEMU, open YouTube

For Gmail/Outlook setup, WhatsApp usage, daily briefing, and GitHub upload, read README.md.

SECURITY: Never upload .env, credentials.json, gmail_token.json, or outlook_token_cache.json to GitHub.
